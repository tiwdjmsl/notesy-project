📚 Notesy – Smart Note Sharing Platform

Welcome to Notesy, a simple and modern web-based note sharing platform that allows users to create, upload, and share study notes easily. Built with a Java backend and a HTML, CSS, JavaScript frontend, Notesy is designed to help students organize and access learning materials anytime, anywhere.

🚀 About Notesy

Notesy is a lightweight web application that enables users to manage and share notes efficiently. It provides a smooth and user-friendly experience for students to upload, browse, and access educational content.

The goal of Notesy is to make studying more collaborative, organized, and accessible. With the help of AI chatbot which can assist users with inquiries related to the websites.

✨ Features
📝 Create and upload notes
📂 Organize notes by subjects or categories
🔍 Search and filter notes easily
👥 Share notes with others
